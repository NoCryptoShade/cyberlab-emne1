Nivå 2 — Fang forventede feil

Serveren gikk tom for disk midt i en logglinje. Nå har auth.log én halv linje på slutten. Skal hele verktøyet ditt dø av det? 🪦

def hent_ip(linje):
    return linje.split()[10]

# … inni løkka:

ip = hent_ip(linje) kaller funksjonen

📌 Fagord try: = «prøv dette». except IndexError: = «hvis det smeller med akkurat denne feiltypen, gjør dette i stedet». Finnes ingen try der feilen skjer, leter Python oppover, til linja som kalte funksjonen. Finner den ingen passende except i det hele tatt, krasjer programmet. Det er derfor tracebacken viser flere linjer.

except ValueError: er en hanske 🧤 som bare passer på én type feil. Hva slipper gjennom?

📌 Fagord Skriv alltid hvilken feiltype du venter: except ValueError:. Bare except: uten navn fanger alt, også skrivefeil i din egen kode. Da krasjer programmet aldri, men det lyver.

Nivå 2 — pathlib

Hva om tell.py kunne spørre: «Hvor ligger jeg?» og lete der? Det kan den. Med tre linjer 🧭

__file__/home/kali/logg/tell.py
Path(__file__).parent/home/kali/logg
MAPPE / "auth.log"/home/kali/logg/auth.log
open("auth.log")/tmp/auth.log
📌 Fagord from pathlib import Path henter Path, en sti du kan regne med. Path(__file__).parent er mappa skriptet ligger i. / setter sammen biter av en sti. Det virker på Windows også.

🤖 Skript som starter av seg selv (med cron eller som tjeneste) står ofte i en helt annen mappe enn deg. En systemd-tjeneste starter for eksempel i / hvis ingen mappe er satt. Der redder Path(__file__) deg.
