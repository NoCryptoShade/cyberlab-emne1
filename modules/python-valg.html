01 Dørvakta: if og sammenligninger
Lett▶
Nivå 1 — Kjører den eller ikke?

Programmet ditt har fått en dørvakt 🕴️. Den ser på hver linje og spør: «Stemmer dette?» Ja = linja under kjører. Nei = den hoppes over.

Variablene er satt: bruker = "root" og forsok = 5
if forsok > 3:
if forsok == 3:
if bruker == "root":
if bruker == "Root":
if forsok > 5:
if bruker != "admin":
if "oo" in bruker:
if forsok == "5":
📌 Fagord if er dørvakta. Det den sjekker, heter en betingelse (condition). Svaret er alltid True eller False.
== er lik · != ikke lik · > større enn · in finnes inni
Ett = gir en variabel en verdi. To == spør om noe er likt.

02 Fire dører: if, elif og else
Lett▶
Nivå 1 — Bare én dør åpnes

Ny jobb for dørvakta: Ikke bare ja eller nei, men fire svar, fra 🟢 til 🔴. Hvem havner bak hvilken dør?

forsok = ?

if forsok > 20:
    print("🔴 Blokker IP-en")
elif forsok > 5:
    print("🟠 Varsle SOC")
elif forsok > 0:
    print("🟡 Følg med")
else:
    print("🟢 Alt rolig")

forsok = 3🟡 Følg med
forsok = 6🟠 Varsle SOC
forsok = 50🔴 Blokker IP-en
📌 Fagord elif = «ellers, hvis». else = «ellers», den siste døra. Python sjekker ovenfra og ned, og bare den første som stemmer kjører. Så hopper den forbi hele blokken.

03 Mellomrom som betyr noe
Middels▶
Nivå 2 — Innrykk

I Python er fire mellomrom ikke pynt. De bestemmer hva dørvakta passer på 👀

forsok = 2
if forsok > 3:
    print("For mange forsøk!")
    print("Sjekk IP-en")
print("Ferdig")
📌 Fagord Mellomrommene foran heter innrykk (indentation). Linjene med samme innrykk under if er en blokk. Linja med if slutter alltid med kolon : Vanlig innrykk er 4 mellomrom.

En logg kan ha en million linjer. Du skriver koden én gang. Hvordan? Se programmet jobbe 🐍

📍 les.py åpner auth.log. Linjene står i kø.
Første linje, kom fram! Du heter linje nå.
Oct 7 09:10:58 server sshd[1928]: Accepted password for kari …
split(), ord nummer 5: Accepted. Skriver det ut ✍️ Neste!
Oct 7 09:11:03 server sshd[1931]: Failed password for admin from 203.0.113.45 …
Nå heter du linje. Ord nummer 5: Failed. Skriver ut. Neste!
…linje 3, 4, 5, 6 og 7 får samme behandling…
Oct 7 09:14:05 server sshd[1952]: Connection closed by 203.0.113.45 …

05 Lag din egen grep -c
Middels▶
Nivå 2 — Løkke + if + teller

I L12 talte grep -c de feilede innloggingene for deg. Nå bygger du den selv, med alt fra denne leksjonen 🧩

antall = 0
for linje in open("auth.log"):
    if "Failed password" in linje:
        antall += 1
print("Feil passord:", antall)
📌 Fagord antall er en teller (counter). antall += 1 er kortversjonen av antall = antall + 1: «legg til én».

🛑 Vil du stoppe ved første treff? Skriv break inni if-en. Da hopper Python ut av løkka med en gang. Nyttig når loggen er enorm.
